# Candy Location (موقع الحلا) - المركز الرقمي التفاعلي

مشروع تفاعلي مبني باستخدام Next.js 15 و React 19 و TypeScript لتوثيق وتحليل كافة بيانات ومتطلبات متجر وحلويات Candy Location تمهيداً لتطوير التطبيق المخصص والأنظمة المتكاملة.

## 🌟 محتويات المنظومة
- **الموقع والهوية الرقمية:** توثيق الدومين، الهوية البصرية، والألوان والشعارات المعتمدة.
- **أرقام التواصل والسنترال:** توحيد 5 أرقام جوال (3 فروع + 1 توصيل + 1 موقع موحد).
- **وكيل واتساب الهجين (Hybrid AI Bot):** محاكي للرد الذكي والتحويل للبشر.
- **ربط سلة وإدارة المخزون:** إدارة تكاملات API المستودع والفروع مع متجر سلة.
